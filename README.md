# 🧩 Refactorización de Ejercicios en React

Este repositorio contiene una serie de ejercicios originalmente desarrollados en JavaScript, ahora refactorizados utilizando React. El objetivo de este proyecto es practicar la transición de aplicaciones tradicionales basadas en JavaScript a aplicaciones modernas utilizando React, aprovechando sus ventajas como la modularidad, el manejo eficiente del estado y la reutilización de componentes.

## 🔧 Tecnologías Utilizadas

- **React**: Biblioteca de JavaScript para construir interfaces de usuario interactivas.
- **Vite**: Herramienta de construcción rápida para desarrollo moderno de frontend.
- **React Router DOM**: Biblioteca para manejar la navegación en aplicaciones React.
- **GitHub Pages**: Servicio de alojamiento estático para desplegar aplicaciones web.

## 📚 Aprendizaje y Objetivos

- Refactorización de código JavaScript a componentes React.  
- Manejos de estado con `useState`, `useRef` y `useEffect`.  
- Navegación entre componentes con React Router.  
- Práctica de buenas prácticas de React y modularidad de componentes.
